# 平台违规广告处置与申诉

处理违规广告举报、临时限制、申诉和恢复决定。

## 参与方与事实

主要参与方包括平台风控人员、广告主、消费者举报人、内容复核人员。领域资料记录以下事实：

- 平台需要主动识别仿冒专业人士和伪造体验的内容
- 违规视频可能同时存在多个裁剪和投放版本
- 下架、标注与责任追究需要协同而非只做单点删除

## 业务边界

- 举报去重
- 风险分级
- 变体传播
- 申诉期限
- 恢复条件

当前资料按以下边界组织：

- 举报受理
- 临时限制
- 变体关联
- 申诉复核
- 恢复通知

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/enforcement_context.py` 负责读取和校验资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

命令只读取仓库内文件，不需要连接外部业务系统。
